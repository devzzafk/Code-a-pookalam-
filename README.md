
# 🌸 Code a Pookalam

Welcome to the **Code a Pookalam** HTML & CSS session!

This repository contains the starter code used during the workshop.

## 🚀 How to Run

1. Download this repository.
2. Open the folder in **VS Code**.
3. Open `index.html`.
4. Run using **Live Server**.

## 📁 Files

- `index.html` → Structure of the webpage
- `style.css` → Styling of the webpage

## 🧠 What You'll Learn

### HTML

- Basic HTML structure
- Head & Body
- Heading and Paragraph
- Div
- Class
- Linking CSS

### CSS

- Background colour
- Font colour
- Width & Height
- Border
- Border Radius
- Margin
- Basic styling

## 🎨 Challenge

Customize the starter pookalam!

Try changing:

- Background colour
- Circle colours
- Text colour
- Width and height
- Border thickness
- Border radius
- Add more circles
- Create your own unique pookalam 🌼
